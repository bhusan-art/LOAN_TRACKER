# Ledgerly UI Concept — Option 1

Standalone, read-only HTML/CSS/JS prototype. It is intentionally separate from `bhusan-art/LOAN_TRACKER`; no repository files, branches, commits, or deployments were changed.

## Run
Open `index.html` in a modern browser. No build tools or dependencies are required. Internet is only used for the optional Google Font import; system fallbacks are provided.

## Included
- Responsive dashboard concept using Deep Ocean Teal, Emerald and Warm Amber.
- Consistent icon alignment and grouped navigation.
- Clickable navigation for Overview, Loans, Collections, Payments, Calendar, People, Documents, Cash & Forecast, What-if Simulator, Reports, Funding Links, Bank Import and Activity Log.
- Business / Personal / All scope selector (visual demo only).
- Sample financial data only. Buttons are non-persistent demo actions; no API calls or live account data.

## Important
This is a visual prototype, not a Figma source file and not a production integration. Screen-level secondary views are navigable placeholders and should be designed against the relevant existing workflows before implementation.
